# Sonic 3 A.I.R.: English / Spanish and fullscreen — 2026-11-17

Status: **proposal, awaiting approval.**

## Origin

The owner approved the plan in wasm-gaming.github.io `RECORD/2026-11-16.engine-settings-screen.WIP.md`.
On 2026-11-17 the owner said "sigue con los motores". That plan gives Sonic 3 A.I.R. a smaller
part: its own Options menu already has the display settings (upscaling, filtering, scanlines),
applied live, so the app gets **no "Ajustes" entry**. This is that part. It changes nothing until
approved.

## Plan

- **engine-specs `^0.5.1` → `^0.6.0`**. The app imports the helpers from `../engine-specs.js`.
- **English and Spanish**:
  - the app's strings (pause menu, boot and error screens) move into one `{ en, es }` table, read
    through `host.locale ?? resolveLocale()`;
  - the game's own menus stay as the game ships them.
- **Fullscreen**:
  - `createFullscreenToggle(root)` (Cmd+Enter / Alt+Enter, Select + Y);
  - a "Pantalla completa" entry in the pause menu.
- **Wake Lock while playing**: proposed, though it was not in the original list for this engine.
  It costs nothing and helps on phones. Fixed on, with no setting, since there is no Ajustes screen
  here.
- **Checks**: `make test` / build. In Chromium, with the owner's test files: en / es, fullscreen by
  key and by menu, and the game's own Options unaffected.
- **Release**: minor.
- **Order**: last of the engines.
