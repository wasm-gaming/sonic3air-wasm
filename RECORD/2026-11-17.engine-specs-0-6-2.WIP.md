# engine-specs 0.6.2: Escape in fullscreen

## 2026-11-17 19:00 UTC — Plan

engine-specs 0.6.2 makes `createFullscreenToggle()` keep Escape for the pause menu in fullscreen
(Keyboard Lock in Chromium; elsewhere the Escape the browser took is given back). The app uses the
toggle, so the bump is enough: `@wasm-gaming/engine-specs` `^0.6.2`, lockfile updated; the build
copies the runtime next to the SDK.

0.6.2 also lets an app's menus take the keys bound to the pad's buttons (`setKeyAliases`). Not
used here: this app has no controls of its own (the game's Options hold them), so there is nothing
to alias.
